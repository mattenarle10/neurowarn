# 🧠 Neurowarn BCI System

Welcome to the **Neurowarn BCI System** GitHub repo!  
This project integrates a Brain-Computer Interface (BCI) with a smart wheelchair for hands-free navigation using EEG signals.

---

## 🧰 System Components

The system includes two main hardware components:

1. 🧢 **EEG Headset** – Emotiv Insight (or any compatible Emotiv model)
2. ♿ **Smart Wheelchair** – Standard wheelchair upgraded with:
   - Control Module (for movement)
   - Sensor Module (for obstacle detection)

---

## 🧠 Part 1: EEG Headset Setup

### 🔧 What You Need

- 💻 Laptop with Emotiv software installed  
- 🧢 Emotiv Insight headset (or other compatible model)

### 🛠️ Setup Instructions

1. Attach the **rear arm** to the headset  
2. Attach the **sensors** to the headset  
3. Press the **power button** to turn on the device  
4. Open the **Emotiv app** and pair the headset  
   - *(See "Software Setup" section for app installation details)*  
5. Position the headset:
   - Reference sensors should touch skin **behind each ear**
   - Frontal sensors should be about **three finger-widths above eyebrows**
   - Re-moisten sensors with **rehydration solution** if needed  
6. Once connected, the app will show the **Mental Commands Dashboard** 🧠✅

---

## ♿ Part 2: Smart Wheelchair Setup

### 🔧 What You Need

- ♿ Electric wheelchair  
- ⚙️ Control module  
- 📡 Sensor module (LiDAR + Ultrasonic)  
- 💻 Laptop with Neurowarn BCI software installed

### 🛠️ Setup Instructions

1. Disconnect the original joystick/controller  
2. Connect the **control module** to:
   - Wheelchair **motors**
   - Wheelchair **battery**  
3. Connect the **control module** to the laptop via **USB or serial**  
4. Turn on the control system using the **power switch**  
5. Mount the **sensor module** securely:
   - Place **LiDAR** at the front  
   - Place **ultrasonic sensor** at the rear  
6. Connect the sensor module to the **laptop**

✅ You now have:

- The **Control Module** – for movement control  
- The **Sensor Module** – for environmental awareness  

---

## 🚀 Final Step: Run the Neurowarn Software

After completing both setups:

1. Launch the **Neurowarn BCI software** on your laptop  
2. Follow the in-app instructions to perform initial tests and begin using the system
